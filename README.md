# Excel-Gemini-AI-Tool (VBA自動生成アシスタント)

Excelの中から一歩も出ずに、Googleの最新AI「Gemini API」を使ってVBAコードを自動生成する強力なマクロツールです。

## 🚀 収録されている2つのツール（機能）

このリポジトリには、用途に合わせて選べる2つのVBAコードが収録されています。用途に合わせて `Excel-Gemini-VBA-Assistant.xlsm` 内に貼り付けてご使用ください。

### 1. シンプルセル出力マシーン (`1_Gemini_to_Cell.txt`)
- **特徴:** 生成された結果を、指定したExcelのセルに直接書き出す、最もシンプルで直感的な基本コードです。
- **用途:** 短いコードの生成や、まずはExcelのシート内だけで完結させてサクッと試したい場合に最適です。

### 2. 【推奨】文字数制限突破マシーン (`2_Gemini_to_DesktopText.txt`)
- **特徴:** AIからの回答がどれだけ長くなっても、Excelの文字数制限（32,767文字）で途切れないように設計された最新のコードです。
- **動き:** ボタンを押すと、生成されたVBAコードがデスクトップにテキストファイルとして自動保存され、メモ帳がポンッと立ち上がって全文字を綺麗に表示します。

## 🛠️ 使い方
1. 本リポジトリから **`Excel-Gemini-VBA-Assistant.xlsm`** をダウンロードして開きます。
2. VBA画面（Alt + F11）を開き、コード内の `YOUR_GEMINI_API_KEY` の部分にご自身のGemini APIキーを入力して保存します。
3. シートの `B6セル` に「やってほしい処理（例：縦横の表を作って合計を求める）」を入力します。
4. ボタンを押すとマクロが実行されます。

## 📌 開発環境 / 推奨モデル
- Excel VBA (ServerXMLHTTP通信)
- Gemini 2.5 Flash (`gemini-2.5-flash`)
