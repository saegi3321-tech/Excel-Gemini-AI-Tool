# Excel-Gemini-AI-Tool (VBA自動生成アシスタント)

Excelの中から一歩も出ずに、Googleの最新AI「Gemini API」を使ってVBAコードを自動生成する強力なマクロツールです。

## 🚀 主な機能
- **VBAコード自動生成:** 実行したい処理を日本語で入力するだけで、AIが最適なVBAコードを生成します。
- **文字数制限の突破（テキスト出力）:** Excelのセル文字数制限（32,767文字）に引っかからないよう、生成されたコードは自動的にデスクトップにテキストファイルとして保存され、メモ帳で即座に開きます。

## 🛠️ 使い方
1. 本リポジトリから `Book1.xlsm` をダウンロードして開きます。
2. VBA画面（Alt + F11）を開き、コード内の `YOUR_GEMINI_API_KEY` の部分にご自身のGemini APIキーを入力して保存します。
3. シートの `B6セル` に「やってほしい処理（例：縦横の表を作って合計を求める）」を入力します。
4. ボタンを押すと、一瞬でデスクトップにコードが生成され、メモ帳が立ち上がります。

## 📌 開発環境 / 推奨モデル
- Excel VBA (ServerXMLHTTP通信)
- Gemini 2.5 Flash (`gemini-2.5-flash`)
